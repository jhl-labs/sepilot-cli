TUI 권한 명령 설치 Desktop

터미널 AI 에이전트

에이전트에게 얼마나 맡길지, 키 하나로 정합니다.

sepilot은 로컬 데몬 sepilotd를 내장한 단일 실행 파일입니다. 터미널에서 대화하며 파일을 읽고 고치고 명령을 실행하고, 같은 명령을 스크립트와 CI에서도 씁니다.

설치하기 GitHub
sepilot — ~/projects/web-shop

› 설치 안내가 틀렸어. README 고치고 테스트 돌려줘

계획: 파일 확인 → 문서 수정 → 테스트 실행

1fs.read README.md
2fs.edit README.md
3terminal.run npm test
Shift+Tab

모드 버튼을 누르거나 버튼에 포커스한 채 Shift+Tab을 눌러 보세요. 같은 요청이라도 모드에 따라 자동으로 실행할 일과 승인을 받을 일이 달라집니다.

인라인 TUI

무엇을 하는지 보이게 일합니다

인자 없이 sepilot을 실행하면 터미널 기록 위에 이어서 그리는 TUI가 열립니다. 화면 전체를 차지하지 않으니 스크롤로 지난 작업을 그대로 돌아볼 수 있습니다.

  • Now · Next — 도구를 쓰기 전마다 지금 하는 일과 다음 단계를 한 줄씩 밝힙니다.
  • 도구 카드 — 읽은 파일, 검색어, 실행한 명령이 결과와 함께 접혀 남습니다.
  • 상태 줄 — 권한 모드, 모델, 컨텍스트 사용량, 역할 봇을 늘 보여 줍니다.
  • @파일 첨부, 클립보드 이미지, !로 시작하는 로컬 셸 명령, 외부 편집기 작성을 지원합니다.
권한 모드

Shift+Tab으로 바로 바꿉니다

실행 중인 작업에도 즉시 적용됩니다. 권한은 정책 엔진이 판단하므로 모드를 바꿔도 금지된 도구가 열리지는 않습니다.

supervised모든 변경과 명령을 승인받습니다.
accept-edits파일 편집은 바로, 명령은 승인받습니다.
workspace-write작업 폴더 안의 편집만 바로, 명령은 승인받습니다.
readonly살펴보고 답만 합니다.

실제 TUI 상태 줄. 승인 요청에는 한 번만, 이 세션 동안, 이 실행 동안, 항상 허용과 거부 중에서 고릅니다.

슬래시 명령

/를 누르면 모든 것이 나옵니다

모델, 역할 봇, 실행 모드를 대화 중에 바꾸고, 패널을 열어 상태를 확인합니다.

  • /model /provider /bot /mode /thinking
  • /new /resume /compact /rewind /fork /share
  • /diff /approvals /tasks /jobs /usage /artifacts
  • /skills /memory /mcp /rag /swarm /settings
데몬

필요할 때 알아서 켜지는 데몬

바이너리에 데몬이 들어 있어 sepilot을 실행하면 필요할 때 띄웁니다. 데스크톱 앱과 같은 데몬을 함께 써서 세션과 설정을 공유합니다.

  • sepilot start · stop · restart · status
  • Linux에서는 sepilot daemon install-service로 로그인 시 자동 시작
  • HTTP·WebSocket API와 OpenAPI 문서, A2A 에이전트 카드, ACP 서버

파이프로 넘기기

표준 입력을 그대로 질문에 붙입니다.

git diff | sepilot ask "이 변경을 리뷰해 줘"

이벤트를 줄 단위 JSON으로

다른 도구가 진행 상황을 읽도록 스트리밍합니다.

sepilot -p "테스트 실패 원인을 찾아줘" \
  --output-format stream-json

역할 봇과 권한 지정

이번 턴에만 봇과 권한을 정합니다.

sepilot ask --bot code-reviewer \
  --autonomy readonly "src/ 보안 점검"

백그라운드 실행

터미널을 닫아도 데몬이 이어서 처리합니다.

sepilot ask --background --wait "릴리스 노트 초안"
sepilot jobs # 진행 중인 작업

설치

한 줄로 설치합니다

설치 스크립트가 플랫폼에 맞는 GitHub Release를 받아 SHA-256 체크섬을 확인합니다. 설치 후 sepilot init으로 모델 제공자를 연결하세요.

바이너리

Linux(x64, arm64), macOS(x64, arm64), Windows(x64).

curl -fsSL https://raw.githubusercontent.com/jhl-labs/sepilot-cli/main/packages/bundle/scripts/install.sh | sh
irm https://raw.githubusercontent.com/jhl-labs/sepilot-cli/main/packages/bundle/scripts/install.ps1 | iex
업데이트는 sepilot upgrade로 합니다.

소스에서 빌드

Node.js 22, pnpm 10이 필요하고, 단일 바이너리는 Bun으로 만듭니다.

git clone https://github.com/jhl-labs/sepilot-cli.git
cd sepilot-cli
pnpm install --frozen-lockfile && pnpm build
./install-cli.sh
Sepilot은 소스 공개(source-available) 라이선스로 배포됩니다. 개인과 기업 모두 수정하지 않은 소프트웨어를 사용할 수 있습니다. Sepilot Desktop · sepilot-cli
